# Visuels des jeux (Feu de camp)

Dépose ici l'image officielle de chaque jeu, nommée d'après son identifiant :

- `outerwilds.jpg`
- `dofus.jpg`
- `tunic.jpg`

Les formats `.png` et `.webp` marchent aussi. Ratio conseillé : 16:10 ou 16:9, au moins 640 px de large. Astro l'optimise au build. Sans image, une illustration abstraite s'affiche.

Prends les visuels dans les **kits presse officiels** des éditeurs (faits pour ce type d'usage), puis renseigne la mention à afficher dans `credits.json`, par exemple :

```json
{ "outerwilds": "© Mobius Digital / Annapurna Interactive" }
```
